## 信息来源优先级

文档与实现发生冲突时，按以下顺序判断：

1. 自动化测试与实际运行结果；
2. 当前代码和配置；
3. 根目录 `README.md`；
4. 本目录中的设计与规划文档。

发现偏差时，应在同一个变更中同步代码、测试和相关文档，避免让规划描述被误认为已经实现。

## 当前项目快照

- Python 3.9+，测试框架为 Pytest；
- FastAPI 演示服务和 MySQL 组成可本地复现的被测系统；
- 6 条 YAML 数据用例，加 4 条 API 对象/安全边界用例；
- 72 条框架单元测试；
- 支持 JSONPath、业务码和数据库断言；
- 支持 Docker Compose、GitHub Actions、Allure 和飞书通知。

以上数字来自 2026-10-07 的仓库状态。新增或删除用例时，请同步更新本页。
